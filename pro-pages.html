02 / Pro pages

Créer et configurer une page PRO

Une page PRO transforme un profil individuel en une vitrine d’entreprise ou de marque. C’est la meilleure manière de capturer des demandes B2B, afficher des preuves de travail, orienter des leads et présenter une trajectoire avec plus de clarté.

Vérification : le workspace ne contient pas l’éditeur de page PRO ni le système de leads. Les champs exacts, les rôles d’administration et les permissions doivent être validés dans l’application déployée avant publication.

1. Différence entre profil et page PRO

Le profil personnel met l’accent sur la progression, les projets et le porteur de projet. La page PRO, elle, sert à convertir un intérêt en action : réservation de démo, demande de pitch deck, candidature, recrutement ou accès à un repo.

  • Profil : parcours, travail, preuve, réputation.
  • Page PRO : vitrine commerciale, CTA, conversion, qualification.

2. Créer une page PRO

  1. Ouvrez le mode création de page PRO dans le tableau de bord.
  2. Sélectionnez le type de présence : entreprise, équipe, studio, communauté ou marque.
  3. Renseignez le nom, la description, le logo, la bannière et le site web.
  4. Activez le CTA et les sections clés de la vitrine.
Tip : Un bon CTA répond à une seule question : “Que veux faire la personne qui arrive ici ?”

3. Configurer le CTA

Le CTA est le point de conversion principal. Il orientera les visiteurs vers l’action la plus utile pour votre contexte : démonstration, investissement, recrutement, collaboration ou documentation.

Objectif Exemple de CTA Risque à surveiller
Réservation de démo Calendly, Cal.com, booking lien non fonctionnel ou mauvais contexte
Pitch deck document de présentation document confidentiel exposé publiquement
Recrutement postes et candidatures offres obsolètes ou accès non maîtrisés
Externe GitHub, Discord, site web redirection vers le mauvais domaine 
Exemple de CTA
Objectif : sales
Label : Réserver une démo
URL : https://cal.com/mon-projet
Type : external

4. Optimiser la vitrine

La page PRO doit être plus qu’un simple résumé. Ajoutez des éléments qui rendent la valeur immédiatement compréhensible.

  • Texte de positioning clair.
  • Preuves visibles : jalons, résultats, captures, démonstrations.
  • Informations de contact ou de qualification.
  • Sections de preuve sur les livrables et les résultats.

5. Rôles et administration

La gestion de la page PRO implique des admins, parfois plusieurs personnes, parfois une équipe. Les rôles, les invitations et les niveaux d’accès doivent être validés dans le produit réel avant de promettre une sécurité ou une gouvernance précise.

Note : Les pages PRO doivent être lisibles, rapides, cohérentes et orientées vers une conversion sans friction.
